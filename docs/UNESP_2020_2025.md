## Implantação pela TI
1. Obter o pacote `UNESP_2020-2025_PRONTO_SERVIDOR.zip` enviado pelo responsável do projeto.
2. **Mesclar** a pasta `acervo/` do ZIP na pasta principal da hospedagem do aplicativo. Não substituir a pasta `acervo/` inteira, pois já existem documentos de outras instituições.
3. Publicar o código atualizado do GitHub na hospedagem do Instituto, caso essa implantação não seja automática.
4. Manter os caminhos relativos exatamente como em `acervo-dados.js`, por exemplo: `acervo/unesp/2023/2a-fase/unesp-2023-2a-fase-prova.pdf`.
5. Configurar os PDFs com `Content-Type: application/pdf` (ou `application/octet-stream`) e respostas **HEAD e GET** funcionando.
6. Testar no computador e no celular a seleção do ano, fase, visualização e download.

**Importante:** baixar o código do GitHub **não** inclui estes 24 PDFs. São fornecidos separadamente no pacote do servidor. Após a publicação dos PDFs no endereço correto, o aplicativo faz uma checagem HEAD e habilita os botões de visualização e download.

Os registros `pending` serão convertidos em arquivos locais pelo gerador `python scripts/gerar_acervo.py` quando os PDFs existirem fisicamente no diretório do projeto, mas não é obrigatório executar o gerador para habilitar o acesso, se o servidor disponibilizar os documentos nos caminhos indicados.

Respeitar as condições de uso/republicação dos materiais disponibilizados pela UNESP.
