## Publicação no servidor do colégio

1. Baixar o ZIP de PDFs separado, porque o código baixado do GitHub **não inclui** os 24 arquivos.
2. Extrair o ZIP na pasta raiz da hospedagem do aplicativo, **mesclando** a pasta `acervo/` e sem apagar os arquivos já existentes da FUVEST, UNESP e UNICAMP.
3. Publicar o código atual do GitHub na hospedagem, caso não haja implantação automática.
4. Verificar que os documentos respondem `HEAD` e `GET` com HTTP 200 e `Content-Type: application/pdf` ou `application/octet-stream`.
5. Testar no computador e celular a sequência **ENEM → ano → 1º/2º dia → Visualizar / Baixar**.

Até que o servidor reconheça cada PDF, o aplicativo exibe **“Aguardando publicação do PDF no servidor”** sem links quebrados; depois, o código libera automaticamente os botões de visualização e download após a checagem `HEAD`.

Verifique as condições de redistribuição dos materiais antes de publicá-los.
