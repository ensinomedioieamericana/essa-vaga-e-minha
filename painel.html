Como funciona a publicação?

Este é um editor visual. Você pode preparar atualizações aqui, mas elas só aparecem para os alunos depois que o arquivo gerado for enviado ao GitHub por uma conta com permissão. Esta página ainda não tem login próprio: o acesso ao endereço não concede permissão para publicar. Nunca insira RAs, senhas ou dados pessoais.

PUBLICAÇÃO

Preparou suas atualizações?

Baixe um único arquivo com as mudanças. Depois, entre no GitHub com sua conta autorizada, substitua o arquivo gestao-dados.js na raiz do repositório e confirme a alteração. O GitHub Pages publicará a nova versão.

  1. Baixe o arquivo atualizado abaixo.
  2. Clique em Abrir GitHub, escolha Add file → Upload files e envie o arquivo baixado.
  3. Confirme o commit no ramo main e confira o aplicativo.

No futuro, quando houver autenticação institucional e uma API segura, poderemos conectar este painel para publicar diretamente, sem a etapa de envio do arquivo.
