Como funciona a publicação?

Este editor permite preparar e publicar atualizações diretamente no GitHub, usando uma autorização da conta que tem permissão no repositório. Esta página ainda não tem login próprio: abrir o endereço não dá acesso à publicação. Não insira RAs, senhas de alunos ou dados pessoais no conteúdo do aplicativo.

PUBLICAÇÃO

Pronto para colocar no ar?

Clique em Salvar e publicar para enviar as mudanças diretamente ao repositório do Instituto. Não será preciso baixar nem enviar arquivos manualmente.

  1. Preencha ou atualize as informações acima.
  2. Clique em Salvar e publicar e autorize usando um token restrito da sua conta GitHub.
  3. Após a confirmação do GitHub, a publicação no aplicativo ocorre pelo processo normal do GitHub Pages.

O token é usado somente durante a publicação e não é gravado no aplicativo, no GitHub, nem no armazenamento do navegador. Você precisará informá-lo a cada publicação. Se preferir, a exportação manual continua disponível.

Autorizar publicação

Para salvar diretamente no GitHub, use um token de acesso de granularidade fina (fine-grained) da conta que administra o projeto.

Crie um token com acesso somente ao repositório essa-vaga-e-minha e permissão Contents: Read and write. Não use a senha da sua conta GitHub nem a senha que mencionou anteriormente.

Criar token restrito no GitHub ↗

Este token não será armazenado nem colocado no código do site. Por segurança, recomendamos usar um token de curta duração e revogá-lo quando não for mais necessário.
