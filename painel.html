GERENCIAMENTO DE DOCUMENTOS

Banco de Provas

Organize as pastas e publique PDFs diretamente no GitHub do Instituto.

Ver Banco de Provas ↗

1. Escolha o destino

Selecione a instituição, o ano e a pasta onde os documentos ficarão.

É possível digitar um ano novo. Para ENEM e FAMERP, use pastas como dia-1 e dia-2; nos vestibulares, 1a-fase e 2a-fase. Também é possível criar qualquer outra pasta.

Para criar uma subpasta, separe os nomes com /, por exemplo: 2a-fase/questoes-discursivas. A pasta aparecerá na navegação dos alunos, inclusive antes de receber PDFs.

2. Enviar provas em PDF

Selecione um ou vários arquivos, escolha o tipo e publique em um único commit.

Arquivos públicos
Nenhum arquivo selecionado.

O conteúdo dos PDFs não é alterado. Não use nomes de alunos nem dados pessoais em arquivos públicos. Arquivos já existentes não serão substituídos sem revisão.

Documentos cadastrados

Arquivos do vestibular e ano selecionados no catálogo.

ⓘ
Onde os arquivos ficam?

O botão Publicar envia o PDF e atualiza o catálogo do GitHub. A hospedagem própria do Instituto só receberá esses documentos quando você publicar a versão atualizada do repositório no servidor. O token é solicitado apenas no momento da publicação e não fica salvo.

🔐

Autorizar publicação dos PDFs

Use um token fine-grained do GitHub com permissão Contents: Read and write no repositório essa-vaga-e-minha.

Os PDFs enviados ficarão acessíveis publicamente no GitHub e, após a implantação, no site do colégio. O token não é armazenado.

PUBLICAÇÃO

Pronto para colocar no ar?

Clique em Salvar e publicar para enviar as mudanças diretamente ao repositório do Instituto. Não será preciso baixar nem enviar arquivos manualmente.

  1. Preencha ou atualize as informações acima.
  2. Clique em Salvar e publicar e autorize usando um token restrito da sua conta GitHub.
  3. Após a confirmação do GitHub, a publicação no aplicativo ocorre pelo processo normal do GitHub Pages.

O token é usado somente durante a publicação e não é gravado no aplicativo, no GitHub, nem no armazenamento do navegador. Você precisará informá-lo a cada publicação. Se preferir, a exportação manual continua disponível.

🔐

Autorizar publicação

Para salvar diretamente no GitHub, use um token de acesso de granularidade fina (fine-grained) da conta que administra o projeto.

Crie um token com acesso somente ao repositório essa-vaga-e-minha e permissão Contents: Read and write. Não use a senha da sua conta GitHub nem a senha que mencionou anteriormente.

Criar token restrito no GitHub ↗

Este token não será armazenado nem colocado no código do site. Por segurança, recomendamos usar um token de curta duração e revogá-lo quando não for mais necessário.
